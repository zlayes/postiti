# Post-its

Bureau virtuel de post-its pour tablette Android, avec profils, thèmes, priorités, archives et un compagnon (Poulpo).

- Un seul fichier : `index.html`, aucune dépendance.
- Données sauvegardées en local (localStorage), par profil, par appareil.
- Déployé sur GitHub Pages.

## Dev
Ouvrir `index.html` dans un navigateur, c'est tout.

## Déploiement
Push sur `main` → GitHub Pages publie automatiquement (Settings → Pages → source `main` / `/ (root)`).
